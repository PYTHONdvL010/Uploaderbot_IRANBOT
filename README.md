# Uploaderbot_IRANBOT v1.0.0

ربات آپلود و انتشار فایل، زیرمجموعه IRANBOT.

## امکانات

- 📤 آپلود فایل توسط ادمین
- 📝 کپشن اختصاصی برای هر فایل
- 📝 کپشن همگانی؛ هنگام آپلود با ارسال `1` اعمال می‌شود و با `0` فایل بدون کپشن ثبت می‌شود
- 📂 ساخت و حذف دسته‌بندی
- 📦 حذف فایل/محصول با تأیید دو مرحله‌ای
- 📦 فایل بدون دسته‌بندی؛ مستقیماً زیر دسته‌بندی‌ها نمایش داده می‌شود
- 🔗 ساخت لینک اختصاصی Telegram برای هر فایل
- 🔗 با باز کردن لینک، فایل مستقیماً توسط ربات برای کاربر ارسال می‌شود
- 👥 ثبت کاربران و نمایش ID، username و تعداد دانلودها
- 📢 عضویت اجباری با بررسی عضویت واقعی در کانال
- 💬 پیام خوش‌آمد قابل ویرایش
- متغیرهای پیام خوش‌آمد: `{username}` و `{ids}`
- 🔄 بررسی مجدد عضویت با Inline Button
- ❌ دکمه لغو در مراحل مدیریتی
- ⚙️ پنل مدیریت کاملاً Inline
- 🏷️ نمایش نسخه `1.0.0` در مدیریت

## عضویت اجباری

از مسیر:

`مدیریت → عضویت اجباری`

ادمین می‌تواند ربات را برای کانال تنظیم کند. ابتدا ربات باید با دسترسی ادمین به کانال اضافه شده باشد، سپس یکی از این موارد قابل ارسال است:

- ID عددی کانال
- `@username` کانال
- لینک عمومی `t.me/...`

پس از فعال‌سازی، کاربران عادی هنگام شروع ربات و استفاده از دکمه‌ها بررسی می‌شوند. اگر عضو نباشند، لینک کانال و دکمه `🔄 بررسی عضویت` می‌بینند.

## آپلود فایل

مسیر:

`مدیریت → آپلود`

پیام آپلود فقط این است:

`📤 فایل مورد نظر را ارسال کنید.`

بعد از ارسال فایل:

- متن دلخواه = کپشن اختصاصی
- `1` = استفاده از کپشن همگانی
- `0` = بدون کپشن

سپس دسته‌بندی انتخاب می‌شود:

- دسته‌بندی موجود
- `📦 بدون دسته‌بندی`

بعد از ثبت، لینک اختصاصی فایل نمایش داده می‌شود.

## لینک فایل

برای هر فایل یک Deep Link ساخته می‌شود:

`https://t.me/BOT_USERNAME?start=file_FILE_ID`

این لینک فایل را دوباره آپلود نمی‌کند؛ ربات همان `file_id` ذخیره‌شده Telegram را برای کاربر ارسال می‌کند.

## مدیریت دسته‌بندی

در `مدیریت → دسته‌بندی‌ها` با انتخاب هر دسته‌بندی، امکان حذف آن وجود دارد.

حذف دسته‌بندی، فایل‌های داخل آن را حذف نمی‌کند؛ فایل‌ها به بخش `بدون دسته‌بندی` منتقل می‌شوند.

## مدیریت محصولات

در `مدیریت → محصولات` تمام فایل‌های ثبت‌شده نمایش داده می‌شوند. حذف هر فایل با تأیید انجام می‌شود و پس از حذف، لینک اختصاصی آن نیز دیگر کار نمی‌کند.

## مدیریت کاربران

در `مدیریت → کاربران` تمام کاربرانی که ربات را Start کرده‌اند نمایش داده می‌شوند:

- نام/username
- ID عددی
- تعداد دانلودهای ثبت‌شده

## پیام خوش‌آمد

در `مدیریت → پیام خوش‌آمد` متن قابل ویرایش است.

متغیرها:

- `{username}` → username کاربر یا نام او در صورت نداشتن username
- `{ids}` → ID عددی کاربر

## کپشن همگانی

در `مدیریت → کپشن همگانی` یک کپشن آماده ذخیره می‌شود.

هنگام آپلود:

- `1` → کپشن همگانی
- `0` → بدون کپشن
- متن دیگر → کپشن اختصاصی همان فایل

## متغیرهای محیطی

```env
ADMIN_IDS=123456789
BOT_TOKEN=YOUR_BOT_TOKEN
DB_PATH=/app/data/uploader.db
```

## Railway

برای نگهداری دائمی SQLite، یک Volume روی مسیر زیر متصل کنید:

`/app/data`

و مقدار `DB_PATH` را روی مسیر داخل Volume قرار دهید:

`/app/data/uploader.db`
