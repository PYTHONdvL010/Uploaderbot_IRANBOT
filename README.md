# 🤖 Uploaderbot_IRANBOT
### نسخه 1.0.0 • ربات آپلود و دریافت فایل تلگرام ساخت PYTHONdvL010

رباتی برای **ذخیره، دسته‌بندی و انتشار فایل‌ها در تلگرام** با لینک اختصاصی، عضویت اجباری، مدیریت کاربران و اجرای ساده روی Railway.

---

## 🚀 ساخت سریع روی Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/J5p8kF?referralCode=txNB5I&utm_medium=integration&utm_source=template&utm_campaign=generic)

با زدن دکمه بالا، صفحه ساخت پروژه در Railway باز می‌شود و پروژه آماده استفاده است.

در مرحله ساخت فقط این دو مورد را وارد کن:

- `ADMIN_IDS` → آیدی عددی مدیر
- `BOT_TOKEN` → توکن ربات از BotFather

سپس پروژه را بساز و منتظر اجرای آن بمان.

> 📌 فضای ذخیره‌سازی ربات روی `/app/data` قرار می‌گیرد تا اطلاعات با راه‌اندازی مجدد پروژه از بین نرود.

---

# 🛠️ نصب دستی

اگر می‌خواهی پروژه را در حساب خودت نگه داری:

### 1. دریافت پروژه
ابتدا پروژه را **Fork** کن و سپس در Railway از مخزن خودت استفاده کن.

### 2. ساخت پروژه
در Railway یک پروژه جدید بساز و مخزن خودت را انتخاب کن.

### 3. ساخت فضای ذخیره‌سازی
یک فضای ذخیره‌سازی بساز و مسیر اتصال آن را دقیقاً روی این مقدار قرار بده:

```text
/app/data
```

### 4. متغیرهای لازم

| نام | مقدار |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی عددی مدیر |
| `DB_PATH` | `/app/data/datacenter.db` |

> توکن ربات و اطلاعات مدیر را داخل مخزن عمومی قرار نده.

### 5. اجرا
پس از ذخیره تنظیمات، پروژه را اجرا کن و در تلگرام `/start` را بفرست.

# 📦 امکانات نسخه 1.0.0

## 📤 آپلود فایل
- ارسال فایل توسط مدیر
- مرحله کپشن بعد از ارسال فایل
- کپشن اختصاصی یا بدون کپشن
- انتخاب دسته‌بندی
- گزینه **بدون دسته‌بندی**

## 🔗 لینک اختصاصی فایل
برای هر فایل یک لینک اختصاصی ساخته می‌شود:

```text
لینک → ورود به ربات → دریافت همان فایل
```

کاربر با باز کردن لینک مستقیماً فایل مربوط به همان لینک را دریافت می‌کند.

## 📂 دسته‌بندی‌ها
- ساخت دسته‌بندی
- نمایش فایل‌های هر دسته
- حذف با تأیید
- انتقال فایل‌های دسته حذف‌شده به **بدون دسته‌بندی**

## 🗑️ حذف فایل
مدیر می‌تواند فایل را حذف کند و قبل از حذف تأیید نهایی نمایش داده می‌شود.

## 👥 کاربران
هر کاربری که ربات را برای اولین بار اجرا کند ثبت می‌شود و مدیر می‌تواند:
- آیدی عددی
- نام کاربری
- تعداد فایل‌های دریافت‌شده

را ببیند.

## 📢 عضویت اجباری
مدیر می‌تواند کانال موردنظر را تنظیم کند.

کاربر در صورت عضو نبودن:
1. لینک کانال را می‌بیند.
2. وارد کانال می‌شود.
3. روی بررسی عضویت می‌زند.
4. ربات عضویت را بررسی می‌کند.
5. پس از تأیید، امکان استفاده از ربات فعال می‌شود.

برای بررسی عضویت، ربات باید در کانال دسترسی لازم را داشته باشد.

## 💬 پیام خوش‌آمد
پیام خوش‌آمد قابل تنظیم است.

متغیرهای قابل استفاده:

```text
{username}
{ids}
```

مثال:

```text
سلام {username} 👋

به Uploaderbot_IRANBOT خوش آمدی.

آیدی شما:
{ids}
```

## 📝 کپشن همگانی
مدیر می‌تواند کپشن عمومی برای فایل‌ها تعیین کند:

- `1` → استفاده از کپشن همگانی
- `0` → بدون کپشن
- متن دلخواه → همان متن برای فایل

# ⚙️ روند آپلود

```text
📤 آپلود فایل
      ↓
ارسال فایل
      ↓
📝 ارسال کپشن
      ↓
📂 انتخاب دسته‌بندی
      ↓
ثبت فایل
      ↓
🔗 ساخت لینک اختصاصی
```

در انتخاب دسته‌بندی:

```text
📂 دسته بندی اگه ساختی
📦 بدون دسته‌بندی
↩️ بازگشت
```

اگر **بدون دسته‌بندی** انتخاب شود، فایل مستقیماً در بخش فایل‌های بدون دسته‌بندی قرار می‌گیرد.

---

# 🔗 دریافت فایل

هر فایل شناسه اختصاصی خودش را دارد و لینک آن به شکل پیوند اختصاصی ربات ساخته می‌شود.

کاربر با باز کردن لینک مستقیماً به همان فایل می‌رسد و نیازی به جست‌وجوی فایل در کانال ندارد.

---

# 🧰 مدیریت

بخش مدیریت شامل قسمت‌های اصلی زیر است:

```text
📤 آپلود فایل
🔗 لینک فایل‌ها
📂 دسته‌بندی‌ها
📦 فایل‌ها
👥 کاربران
📢 عضویت اجباری
💬 پیام خوش‌آمد
📝 کپشن همگانی
```

عملیات مدیریتی با دکمه‌های درون‌پیامی انجام می‌شوند.

```text
/app/data
```
